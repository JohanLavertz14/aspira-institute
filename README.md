# Aspira Institute — เว็บไซต์คอร์สเรียนออนไลน์

เว็บไซต์คอร์สเรียนออนไลน์ของสถาบัน Aspira Institute นักเรียนสมัครสมาชิก ซื้อคอร์ส แจ้งชำระเงิน
แล้วเข้าเรียนผ่านคลิปในเว็บได้ทันที พร้อมหลังบ้านสำหรับแอดมินจัดการทุกอย่าง

ข้อมูลในระบบตอนนี้เป็นข้อมูลตัวอย่าง (mock) ทั้งหมด แก้หรือลบทิ้งแล้วใส่ข้อมูลจริงได้เลย

---

## 1. ติดตั้งและรัน

ต้องมี Node.js เวอร์ชัน 20 ขึ้นไป

```bash
npm install
cp .env.example .env      # Windows ใช้ copy .env.example .env
npm run setup             # สร้างฐานข้อมูล + ใส่ข้อมูลตัวอย่าง
npm run dev
```

เปิด http://localhost:3000

> `npm run setup` ครั้งแรกต้องต่ออินเทอร์เน็ตได้ เพราะ Prisma จะดาวน์โหลดเครื่องมือของตัวเองมาเก็บไว้

### บัญชีสำหรับทดลองใช้

| บทบาท | อีเมล | รหัสผ่าน |
| --- | --- | --- |
| แอดมิน | admin@aspira.ac.th | admin1234 |
| นักเรียน | student@example.com | student1234 |

เข้าหลังบ้านที่ `/admin` (เฉพาะบัญชีที่ role เป็น ADMIN)

**ก่อนขึ้นใช้งานจริง ต้องเปลี่ยนรหัสผ่านแอดมิน และเปลี่ยนค่า `AUTH_SECRET` ใน `.env` เป็นข้อความสุ่มยาว ๆ**

## 2. สิ่งที่ทำได้ในเว็บ

### ฝั่งนักเรียน

- หน้าแรก รายการวิชา คอร์สแนะนำ และขั้นตอนการสมัครเรียน
- หน้ารวมคอร์ส กรองตามวิชา ระดับชั้น และค้นหาชื่อคอร์ส
- หน้ารายละเอียดคอร์ส แสดงเนื้อหาทุกบท ราคา และบทเรียนที่ดูฟรีได้
- สมัครสมาชิกและเข้าสู่ระบบด้วยอีเมล + รหัสผ่าน
- สั่งซื้อคอร์ส เลือกโอนธนาคารหรือพร้อมเพย์ ระบบออกเลขที่คำสั่งซื้อให้
- แจ้งชำระเงินพร้อมอัปโหลดสลิป และติดตามสถานะการอนุมัติ
- หน้าเรียน เล่นคลิปจาก Vimeo (รองรับ YouTube และไฟล์วิดีโอด้วย)
- ดาวน์โหลดชีท PDF ประกอบบทเรียน
- แบบทดสอบท้ายบท ตรวจคำตอบอัตโนมัติพร้อมเฉลยและคำอธิบาย
- แถบความคืบหน้า บันทึกว่าเรียนถึงบทไหนแล้ว
- กระดานถาม-ตอบใต้คลิป ตอบกลับกันเป็นชั้นได้

### ฝั่งแอดมิน (`/admin`)

- แดชบอร์ด ยอดขายสะสม ยอดขายเดือนนี้ กราฟ 6 เดือนล่าสุด และคอร์สที่มีนักเรียนมากที่สุด
- ตรวจสอบการชำระเงิน ดูสลิป กดอนุมัติแล้วระบบเปิดสิทธิ์เรียนให้อัตโนมัติ หรือกดไม่อนุมัติพร้อมระบุเหตุผล
- จัดการคอร์ส สร้าง แก้ไข เผยแพร่ ลบ ตั้งราคา และกำหนดจำนวนวันที่เรียนได้
- จัดการบทและบทเรียน ใส่รหัสวิดีโอ ความยาว และตั้งบทเรียนตัวอย่างฟรี
- อัปโหลดชีท PDF เข้าบทเรียน หรือใส่ลิงก์ไฟล์ภายนอก
- สร้างแบบทดสอบท้ายบท เพิ่มข้อสอบ ตัวเลือก คำตอบที่ถูก และคำอธิบายเฉลย
- จัดการวิชา ชื่อ สีประจำวิชา และลำดับการแสดง
- จัดการนักเรียน ดูความคืบหน้าแต่ละคอร์ส ผลแบบทดสอบ คำสั่งซื้อ เปิดสิทธิ์เรียนด้วยมือ ต่ออายุ ปิดสิทธิ์ และระงับบัญชี
- ตั้งค่าเว็บ ชื่อสถาบัน โลโก้ ข้อมูลติดต่อ บัญชีธนาคาร และ QR พร้อมเพย์

## 3. สิ่งที่ต้องใส่เพิ่มก่อนเปิดใช้จริง

ระบบเว้นช่องไว้ให้แล้ว กรอกได้ที่หน้า **หลังบ้าน → ตั้งค่าเว็บ**

- [ ] โลโก้สถาบัน (ตอนนี้แสดงเป็นสัญลักษณ์ตัวอักษร A ไปก่อน)
- [ ] เบอร์โทร อีเมล LINE ที่อยู่ และลิงก์เฟซบุ๊ก
- [ ] ชื่อธนาคาร เลขที่บัญชี ชื่อบัญชี และรูป QR พร้อมเพย์
- [ ] เปลี่ยนรหัสผ่านแอดมิน และตั้ง `AUTH_SECRET` ใหม่
- [ ] ใส่รหัสวิดีโอจริงในแต่ละบทเรียน (ตอนนี้เป็นคลิปตัวอย่างของ Vimeo)
- [ ] อัปโหลดชีท PDF จริงแทนไฟล์ตัวอย่าง (เอกสารประกอบคอร์สทั้งเล่มตั้งได้ที่ หลังบ้าน > จัดการคอร์ส > เอกสารประกอบคอร์ส)

## 4. เรื่องวิดีโอ

ค่าเริ่มต้นใช้ Vimeo ซึ่งเหมาะกับคอร์สที่ขาย เพราะกันการดูนอกเว็บได้ ตั้งค่าใน Vimeo ดังนี้

1. อัปโหลดคลิป แล้วตั้ง Privacy เป็น **Hide from Vimeo**
2. เปิด **Where can this be embedded** เลือก *Specific domains* แล้วใส่โดเมนของสถาบัน
3. คัดลอกตัวเลขท้าย URL (เช่น `https://vimeo.com/76979871` → รหัสคือ `76979871`) มาใส่ในหลังบ้าน

ระบบรองรับ YouTube (แบบไม่เป็นสาธารณะ) และไฟล์วิดีโอโดยตรงด้วย เลือกได้ที่หน้าแก้ไขบทเรียน

## 5. โครงสร้างไฟล์

```
prisma/
  schema.prisma          โครงสร้างฐานข้อมูลทั้งหมด
  seed.ts                ข้อมูลตัวอย่าง แก้หรือลบได้
prisma.config.ts         ตั้งค่า Prisma (connection string อยู่ที่นี่)
src/
  app/
    page.tsx             หน้าแรก
    courses/             รายการคอร์สและรายละเอียดคอร์ส
    checkout/            หน้าสั่งซื้อ
    orders/              คำสั่งซื้อและแจ้งชำระเงิน
    my-courses/          คอร์สของฉัน
    learn/               หน้าเรียน คลิป ชีท แบบทดสอบ ถาม-ตอบ
    login/ register/     สมัครสมาชิกและเข้าสู่ระบบ
    admin/               หลังบ้านทั้งหมด
    actions/             ฟังก์ชันฝั่งเซิร์ฟเวอร์ (auth, orders, learn, admin)
  components/            ส่วนประกอบที่ใช้ซ้ำ เช่น ตัวเล่นวิดีโอ การ์ดคอร์ส
  lib/                   ฐานข้อมูล ระบบล็อกอิน สิทธิ์เรียน อัปโหลดไฟล์ ฟอร์แมตข้อความ
  middleware.ts          ป้องกันหน้า /admin /my-courses /orders
public/uploads/          ไฟล์ที่อัปโหลด (สลิป ชีท โลโก้)
```

## 6. คำสั่งที่ใช้บ่อย

| คำสั่ง | ใช้ทำอะไร |
| --- | --- |
| `npm run dev` | รันโหมดพัฒนา |
| `npm run build` | สร้างไฟล์สำหรับขึ้นเซิร์ฟเวอร์ |
| `npm start` | รันโหมดใช้งานจริง (ต้อง build ก่อน) |
| `npm run db:push` | อัปเดตโครงสร้างฐานข้อมูลตาม schema |
| `npm run db:seed` | ใส่ข้อมูลตัวอย่างใหม่ |
| `npm run db:reset` | ล้างฐานข้อมูลแล้ว seed ใหม่ทั้งหมด |
| `npm run db:seed:chem` | สร้างหรืออัปเดตคอร์ส Foundation for Chemistry จากไฟล์ `prisma/seed-foundation-chemistry.ts` (รันซ้ำได้) |

### จัดการบัญชีแอดมิน

```
npm run admin -- list                                   ดูรายชื่อแอดมินทั้งหมด
npm run admin -- create อีเมล รหัสผ่าน "ชื่อที่จะแสดง"      สร้างแอดมินใหม่
npm run admin -- password อีเมล รหัสผ่านใหม่              เปลี่ยนรหัสผ่าน
npm run admin -- remove อีเมล                            ลบบัญชีแอดมิน
```

รหัสผ่านต้องยาวอย่างน้อย 8 ตัวอักษร และไม่เป็นตัวเลขล้วน ระบบเก็บเป็นค่าแฮชด้วย bcrypt
ถ้ารหัสผ่านมีอักขระพิเศษ ให้ครอบด้วยเครื่องหมายคำพูดเดี่ยว เช่น 'Aspi!ra#2026'

## 6.1 ไฟล์ที่ไม่ถูกเก็บเข้า git

ไฟล์เนื้อหาคอร์สและไฟล์ที่ผู้ใช้อัปโหลด ไม่ถูกเก็บเข้า git โดยตั้งใจ เพราะเป็นของที่ขาย
และ repo นี้เป็นแบบ public

```
.env                            คีย์และ connection string
prisma/dev.db                   ฐานข้อมูล
public/uploads/sheets/          ชีทเรียนและเอกสารประกอบคอร์ส
public/uploads/slips/           สลิปการโอนเงินของนักเรียน
public/uploads/branding/        โลโก้และ QR พร้อมเพย์
```

เวลา clone ไปเครื่องใหม่ ให้ก๊อปไฟล์เหล่านี้ไปเอง หรืออัปโหลดใหม่ผ่านหลังบ้าน
ตอนขึ้นเซิร์ฟเวอร์จริงควรย้ายไฟล์อัปโหลดไปเก็บบน object storage ตามที่อธิบายในหัวข้อถัดไป

## 7. ตอนขึ้นเซิร์ฟเวอร์จริง

ตอนนี้ใช้ SQLite (ไฟล์ `prisma/dev.db`) ซึ่งพอสำหรับเริ่มต้นและทดสอบ ถ้ามีนักเรียนหลายร้อยคนขึ้นไป
แนะนำย้ายไป PostgreSQL ซึ่งแก้แค่ 3 จุด

1. `prisma/schema.prisma` เปลี่ยน `provider = "sqlite"` เป็น `"postgresql"`
2. `src/lib/db.ts` เปลี่ยนจาก `@prisma/adapter-better-sqlite3` เป็น `@prisma/adapter-pg`
3. เปลี่ยน `DATABASE_URL` ใน `.env` แล้วรัน `npm run db:push`

**เรื่องไฟล์อัปโหลด** ตอนนี้เก็บลงโฟลเดอร์ `public/uploads` ถ้า deploy บน Vercel หรือแพลตฟอร์มที่ไฟล์หายเมื่อ redeploy
ให้แก้ฟังก์ชันเดียวคือ `saveUploadedFile` ใน `src/lib/upload.ts` ให้อัปโหลดขึ้น S3 หรือ Cloudflare R2 แทน
ส่วนอื่นของระบบไม่ต้องแก้

**เรื่องบัตรเครดิต** โครงหลังบ้านเตรียมไว้แล้ว (ฟิลด์ `method = CARD` และสวิตช์เปิดใช้งานในหน้าตั้งค่า)
เมื่อพร้อมต่อผู้ให้บริการรับชำระเงิน เช่น Omise หรือ Stripe ให้เพิ่มขั้นตอนสร้าง charge
แล้วเปลี่ยนสถานะคำสั่งซื้อเป็น `PAID` พร้อมสร้าง Enrollment เหมือนที่ฟังก์ชัน `approvePaymentAction` ทำอยู่
